Heptagon Canopy — Overall Size

Clean regular heptagon, no edge pull. The webbing side stays fixed at 10′0″ corner-to-corner — that’s what sets the polygon, so R = 11′6.3″. Each corner’s alpine butterfly (5½″) does not grow the heptagon; it only pushes the spoke-attach point ~5½″ outboard of the corner. Seven long spokes run from a ø 6″ coupling plate to those attach points.

Why the spoke reads ~140″

You caught the earlier error: the butterfly was growing the polygon. It shouldn’t. With the side fixed:

stepradius
corner set by side (10′ → R)138.3″
+ butterfly offset outboard143.8″
− coupling radius (3″)140.8″
So the ~140″ is real — but it comes from the butterfly offset, not a bigger heptagon. Bare corner-to-coupling is 135.3″; the butterfly adds the last ~5½″. Close to one 50-LED bulb (140″), but that’s still coincidence.
Structure vs. reach. The webbing footprint is 23′0.6″ across (corners). The spoke tips reach 23′11.6″ because the butterflies stick out past the rim. The 24′ you saw before was really this tip circle — the earlier plan just mislabeled it as the polygon.
Before cutting, confirm two things: (1) which way the butterfly loop points — the number above assumes it projects outboard (+5½″ past the corner). If instead it sits inboard toward the hub, the spoke shortens to ~129″ and the tape gets ~11″ shorter, so this is worth pinning down on a test corner; (2) that the coupling ends up ~3″ radius — a floppy Dyneema loop purses smaller under load, adding an inch or two back onto each spoke. Both live inside the long-spoke adjuster range, so cut those long and tension to the mark.
