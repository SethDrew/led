◦ board offline but plugged in via USB? — why & how to fix
The dashboard resolves serial ports once at startup and never rescans. macOS renumbers /dev/cu.usbserial-* whenever a board is unplugged/replugged (or the hub re-enumerates), so a reader gets stuck on a dead path — the board is live on USB but reads offline · 0rb · 0gap and its panel just shows stale values. The fix is to restart the dashboard against the current ports. Paste this to Claude:
